Cómo publicar y compartir el recurso con alumnos
  1. Configura el periodo y las materias.
  2. Carga la lista de alumnos (CSV/TXT). Se guarda localmente en tu navegador (IndexedDB).
  3. Pulsa "Publicar lista para alumnos": se descargará un archivo tutor-publicado.html con los hashes embebidos.
  4. Comparte ese archivo con tus alumnos (por Classroom, Canvas, correo o USB). Ellos solo escriben su matrícula para entrar.
  5. La IA funciona con Puter.js (sin API key). Los alumnos necesitan conexión a internet.
