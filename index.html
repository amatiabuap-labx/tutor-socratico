💡 Cómo publicar y compartir el recurso con alumnos
  1. Configura el periodo, materias y las Instrucciones para la IA.
  2. Carga la lista de alumnos (CSV/TXT). Se guarda localmente en tu navegador.
  3. Pulsa "Publicar lista para alumnos": se descargará un archivo tutor-publicado.html.
  4. Sube ese archivo a GitHub Pages reemplazando tu index.html.
  5. Proyecta el Código QR en clase para que los alumnos escaneen y entren.
